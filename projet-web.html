Projet : BottomUp (SAE S3)

Système de vote participatif et démocratique

Contexte du Projet

Ce projet de Semestre 3 (SAE) consistait à développer une application web complète permettant l'interaction entre citoyens autour de questions diplomatiques. L'objectif était de créer un espace avec lequel les utilisateurs peuvent proposer des solutions et voter pour les meilleures idées.

  • Nom du Projet : BottomUp
  • Stack : HTML, CSS, PHP, SQL, JavaScript
  • Contexte / Date / Durée : SAE Semestre 3 (Automne 2025, durée de 6 semaines).
  • Objectif & Contraintes : Développer une application web complète (MVC) avec gestion sécurisée de l'authentification.
  • Composition de l'équipe : 4 étudiants en BUT Informatique.
  • Démarche : Modélisation BDD, développement progressif (back/front) et tests unitaires.
  • Degré d'implication / autonomie : Très autonome sur le back-end (PHP/SQL) et la conception du système de vote.

Fonctionnalités & Méthodes

L'application offre un système complet d'interaction :

  1. Authentification : Système de connexion et de déconnexion sécurisé (rôles admin/utilisateur).
  2. Débats : Création et gestion de questions thématiques (ex : programmation).
  3. Propositions : Soumission de propositions par les utilisateurs avec système de co-auteurs.
  4. Vote : Plusieurs méthodes de scrutin implémentées (Majoritaire, Scrutin Australien).

Compétences Travaillées

  • Frontend : Interface réactive avec HTML/CSS et interactivité via JavaScript.
  • Backend : Logique serveur en PHP (MVC).
  • Base de Données : Modélisation complexe (Utilisateurs, Questions, Votes) et requêtes SQL optimisées.
  • Sécurité : Gestion des sessions et protection contre les injections.

Contribution Personnelle

J'ai participé au développement du système de vote et à la gestion dynamique des propositions Php. J'ai également travaillé sur la structure de la base de données, sur les vues de résultats qui suivent les phases de vote, à l'ergonomie du site et aux systèmes de fusion des propositions.
